# 🃏 OMAHA OPEN — אומהה פתוחים

משחק פוקר אומהה "פתוח" ל-4 שחקנים: כל הקלפים גלויים, 4 סיבובים מאותה חפיסה **בלי ערבוב**. נקודות וירטואליות בלבד — רק המנהל מעניק נקודות.

**לייב:** https://omaha-open.onrender.com

---

## הפעלה מקומית

```
node server.js
```
פותח על http://localhost:3777 (וגם בכתובת הרשתית להתחברות מהטלפון באותו WiFi).

## בדיקות

```
node engine-test.js      # מנוע אומהה, כספים, חשבונות, משחק מלא
node stress-test.js      # 20 שחקנים במקביל + מרוצי-תנאי
node shuffle-test.js     # אקראיות הערבוב (סטטיסטי)
node google-test.js      # אימות טוקן Google
```

## משתני סביבה

| משתנה | תיאור |
|-------|-------|
| `ADMIN_PIN` | קוד המנהל לדאשבורד (ברירת מחדל 1302 — **שנה בענן!**) |
| `GOOGLE_CLIENT_ID` | מזהה OAuth של Google (אופציונלי — מפעיל כפתור "המשך עם Google") |
| `PORT` | פורט (ברירת מחדל 3777) |

## איך משחקים

1. נרשמים (אימייל+סיסמה או Google) עם **קוד הזמנה** שהמנהל נותן.
2. המנהל מעניק נקודות (⚙ → קוד מנהל → הפקדה).
3. פותחים שולחן (רגיל 52.5 / גבוה 105) או מצטרפים לשולחן פתוח בלובי.
4. צריך בדיוק 4 שחקנים. מנצח כל סיבוב לוקח רבע קופה. סוויפ (4/4) = הכפלה.
5. משחק עם בוטי דמו = **אימון בלי נקודות**.

## דאשבורד מנהל (⚙)

יתרות כל השחקנים · הפקדה עם עמלת 5% · שינוי יתרה · איפוס סיסמה · החלפת קוד הזמנה · **גיבוי/שחזור** (הורד גיבוי אחרי כל ערב — בענן החינמי הנתונים מתאפסים בכל דיפלוי).

## פריסה לענן (Render)

1. השירות מחובר לריפו `bke1302/omaha-open`.
2. **Settings → Auto-Deploy → On** — כדי שכל פוש יעלה אוטומטית.
3. **Settings → Environment** — הגדר `ADMIN_PIN` (חזק!) ו-`GOOGLE_CLIENT_ID` (אם רוצים Google).

## הפעלת התחברות Google

1. console.cloud.google.com → פרויקט חדש.
2. **OAuth consent screen** → External → מלא פרטים.
3. **Credentials → Create → OAuth client ID → Web application**.
4. **Authorized JavaScript origins:** `https://omaha-open.onrender.com` וגם `http://localhost:3777`.
5. העתק את ה-Client ID → הגדר כ-`GOOGLE_CLIENT_ID` (ב-Render ומקומית).

הכפתור מופיע אוטומטית כשהמזהה מוגדר. כניסה ראשונה דרך Google עדיין דורשת קוד הזמנה.

## אבטחה ואמינות

נבדק ע"י 5 סוכני ביקורת (מנוע, ריבוי-שחקנים, עיצוב, אבטחה, כספים):
מנוע אומהה מדויק (אומת מול כל 2.6M הידיים), שימור-כסף מוחלט, אין race conditions, ערבוב קריפטוגרפי. הגנות: הצפנת סיסמאות אסינכרונית, הגבלת קצב, כתיבה אטומית עם גיבוי, refund קופה בכיבוי מסודר, התקדמות סיבובים אוטומטית (נטישת מארח לא משמידה נקודות), אימות טוקן Google מלא.
